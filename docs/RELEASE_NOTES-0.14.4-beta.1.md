# Roomcast 0.14.4-beta.1

本地候选包；本轮未推送 GitHub、打标签或创建 Release。已发布的 beta.7 保留。

## 变化和操作

- 新邀请默认使用 [Roomcast 观看站点](https://roomcast-2dy.pages.dev/)，不再依赖 GitHub Pages 加载首页。只有 Windows 客户端建房；手机网页观看，电脑网页加入后仍可共享。旧链接和旧站点不删除。
- 主预览、小窗的信息栏在画面顶部悬浮，鼠标移动及自动隐藏不改变视频区域；全屏不显示信息栏。只显示共享人、分辨率、FPS、码率和 P2P/VDO/TURN；长昵称省略，测量尚不可用显示 —。
- OBS 停止不排在卡住的启动/枚举任务后面；取消旧操作，晚返回不得恢复旧采集。清理先设总预算，超时只处理 Roomcast 所属子进程。仍使用原来的停止、退出和 ×，无需额外停止按钮。
- 控制回包绑定原始连接，异常回包不能完成其他成员的等待；连接关闭时立即结束对应等待，对请求积压设上限。
- 设置→关于新增“导出诊断”：最近 200 条本会话阶段与耗时，只保存在内存、不自动上传，不包含邀请、密钥、地址、成员或聊天。
- 不再随新包分发闲置 cloudflared，继续附带 OBS/音频运行时、许可证和 OBS 对应源码。未来发布流程阻止覆盖已公开附件。

## 验证范围

具体新包摘要、验证结果和失败记录在本版检查表及 [时间戳](时间戳记录/最小优化与域名调整-20260927.md)。本机新站点直连成功不代表所有设备/网络可达；网页能加载也不代表信令和媒体必然可达。

TURN 获取、凭据 TTL、ICE、P2P/VDO/TURN 顺序及鉴权协议保持。更新下载仍来自 GitHub；当前未更换更新资产托管。版本仍为未签名 Windows x64 测试版。

成员身份恢复、可撤销邀请、共享编码与独立签名需要另外的协议、性能或身份方案；本版没有把这些当作已完成。借鉴机制为独立实现，没有复制 Piik 源码。

窗口销毁后，迟到的设置或权限消息会被安全拒绝，避免退出/更新时 Object has been destroyed。修复更新隐藏启动器未执行脚本的已复现故障；启动确认、校验后安装和旧进程退出等待保留，支持中文路径。
