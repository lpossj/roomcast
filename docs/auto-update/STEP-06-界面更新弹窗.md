# STEP-06 界面接入：启动更新弹窗记录

> 时间：创建于 2026-09-26 15:17（取自文件系统）；本步的完整时间线见 [TIMELINE-全程时间戳记录.md](TIMELINE-全程时间戳记录.md)。

- 前置：STEP-05（主进程与更新窗口）。
- 本步改动：`src/App.jsx`、`src/preferences.js`、`src/styles.css`。

## 1. 需求对应

| 用户要求 | 实现 |
| --- | --- |
| 自动检查出最新版本后，在初始页面弹出二级 UI | 新增 `UpdatePromptModal`，由 `update.result.available` 触发，叠加在初始页面上 |
| 显示最新版本 | 标题「发现新版本 X」，副标题「当前版本 Y」（含"公开测试版"标记） |
| 显示更新内容 | 可滚动区域显示发布说明；为空时显示"本次更新没有提供说明。" |
| 可选「不再弹出此框」 | 复选框，勾选后把该版本号写入偏好 `dismissedUpdateVersion`，之后同一版本不再弹出（下一个版本仍会弹出） |
| 可选「立即更新」 | 主按钮，调用 `roomcast:update-start` |
| 用户可以选择叉掉关闭提示 | 右上角 ✕ 与「稍后」都只关闭弹窗，不做任何安装动作 |

## 2. 实现要点

1. **自动弹出时机**：沿用原有"启动 4 秒后自动检查"的逻辑；检查结果到达后由独立 `useEffect` 决定是否弹窗。
   条件：桌面端 + `available` + 该版本未被"不再弹出" + **当前没有其他弹窗**。
   最后一条是为了避免与设置/共享/邀请弹窗叠在一起；被让路的弹窗关掉后条件重新成立、提示仍会出现。
2. **安装能力探测**：挂载时调用一次 `roomcast:update-target`，得到
   `{kind, supported, reason}`。不支持时（源码/开发模式、非 Windows、目标结构不符）
   弹窗与设置面板都改为"打开发布页下载"，并显示具体原因，绝不静默什么都不做。
3. **点击立即更新**：把复选框状态先落盘（若勾选），然后调用 `roomcast:update-start`。
   返回 `{ok:false, unsupported:true, reason}` 时把面板切到"不支持自动更新"并显示原因；
   抛错时在同一弹窗内显示错误，不关闭窗口。
4. **设置面板同步增强**：`UpdateSection` 在有新版本且支持自动更新时增加「立即更新到 X」主按钮；
   不支持时显示原因 + 手动下载按钮。手动下载 EXE/ZIP、打开文件位置、"打开发布页"全部保留。
5. **文案更正**：原说明写「本版不会自动替换正在运行的程序」，与现在的行为矛盾，
   已改为描述真实流程（下载 → 发布页 SHA256.txt 校验 → 校验通过才关闭程序、覆盖目录并自动重开；
   没有校验文件或校验不一致就不安装），并保留"产物未签名，校验值只能说明与发布页一致"的边界说明。
6. **偏好白名单**（`src/preferences.js`）：加入 `autoCheckUpdates`、`dismissedUpdateVersion`。
   没有这一步，开关与"不再弹出"都会静默失效（原 `autoCheckUpdates` 就是这个状态）。
7. **样式**（`src/styles.css`）：新增 `.update-prompt*` 规则；更新内容区限高 240px 可滚动，
   避免长更新日志把「立即更新」按钮挤出屏幕；使用既有主题变量（`--muted`、`--border`）。

## 4. 验证

- `vite build` 通过（1841 个模块，无 JSX/语法错误）。
- 全量测试 180 项：177 通过（含 14 项本次新增的更新相关用例）。
- 人工静态复核：hook 调用顺序稳定（新增 state/effect 均在组件顶层、无条件调用）；
  自动弹窗的 effect 依赖 `[desktopChrome, update.result, dismissedUpdateVersion, modal]`，
  不会因同一结果重复触发（`current.open ? current : {...}` 保持幂等）。

## 5. 审查结论与遗留

- 弹窗只做提示与触发，不改动共享/房间状态，关闭（✕ / 稍后）对正在进行的共享零影响。
- 网页端（非桌面）不显示该弹窗：`desktopChrome` 为假时直接返回。
- 未做视觉走查（无法在本机启动 GUI 截图）；样式改动是新增类，未覆盖既有选择器。
