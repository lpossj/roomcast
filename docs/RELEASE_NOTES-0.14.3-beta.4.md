# Roomcast 0.14.3-beta.4

## 修复

**自动更新不再弹出多余的命令行窗口。** 在 Windows 上启动替换脚本的方式会与"隐藏窗口"标志冲突
（`DETACHED_PROCESS` 会让 `CREATE_NO_WINDOW` 失效），导致下载/校验/覆盖阶段冒出黑框 ——
用户实测出现过三个 cmd 窗口。现在替换脚本使用真正的隐藏控制台，它调用的
`tasklist` / `ping` / `robocopy` 都继承同一个不可见控制台，**全程不会再出现任何窗口**。
用"可见控制台窗口计数器"做了对照实验：旧方式 +1～3 个窗口，新方式 0 个。

**软件更新面板去掉"下载便携版 EXE / 下载 ZIP"两个按钮。** 自动更新已经能自行下载、校验并安装，
逐个资产的下载按钮只是重复入口；手动下载统一走「打开发布页（手动下载）」。
随之移除了不再使用的下载/打开文件位置通道（渲染层、预加载与主进程 IPC），
界面与代码都更简单。

## 保持不变

- 自动更新的完整流程：启动弹窗（版本 / 更新内容 / 不再弹出此框 / 立即更新 / 可关闭）→
  关闭正在运行的程序 → 下载进度 → SHA256 校验 → 解压 → 退出后覆盖程序目录 → 自动重新打开。
- 必须校验：缺少发布页 `SHA256.txt` 或校验不一致时不会安装。
- 接口限流时改用固定站点版本清单继续检查，界面如实标注。
- 程序未能退出、安装目标不合法、替换脚本未能启动等情况一律取消更新且不改动原程序。

## 边界

Windows 产物仍未签名，SmartScreen 可能提示未知发布者；`SHA256` 只能证明文件与发布页一致。
覆盖过程没有回滚，中途断电可能留下半新半旧目录。程序装在 `Program Files` 等无写权限位置时更新会失败并提示。
