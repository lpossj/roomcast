# Roomcast 0.14.3-beta.6

## 修复

**手机连不上房间（iOS 报 `negotiation_failed`、安卓报无法建立 P2P 连接）。**
移动网络（运营商 CGNAT／对称 NAT）几乎必须靠中继（TURN）才能打通，而这一版修掉了两个真实缺陷：

1. **中继凭据会过期，却从不刷新。** 房主向 Worker 取的 TURN 凭据有效期 1 小时，建房时取一次就写进房间与邀请链接，之后再没更新过；房间开满一小时（或用旧邀请）后，新加入的手机拿到的是**已失效的中继**，在移动网络下直接连不上，界面却什么都不说。现在**分发邀请前会重新取一次凭据**，复制出去的链接一定带有效中继。
2. **没有中继时界面不提示。** 取不到凭据时会静默降级成"只有 STUN"，邀请照常可复制。现在「分享房间」会明确写出：「当前房间没有可用的中继（TURN）：手机在移动网络下通常连不上这台电脑。可在『设置 → 网络』里启用 Cloudflare TURN 中继，然后重新建房。」

> 注意：VDO.Ninja 备用车道**仍然按设计只走直连**（`turnServers:false` / `autoRelay:false`，由两条项目自检守着），所以移动网络下真正能救场的是你自己的中继。启用方式见 `docs/Cloudflare-TURN部署.md`。

**程序关不掉（TURN 建不起来、网页端连不上、房主移交失败时退不出）。**
关窗与退出原先被绑在网络结果上：移交失败时渲染层回 `ok:false`，主进程把它当**否决票**；那个 20 秒计时器到点只清掉自己的标志、并不关窗；`before-quit` 里的收尾没有任何期限。现在：

- 关闭窗口给 **2.5 秒**预算，到点**无条件关闭**；
- 2.5 秒内**再点一次 ✕ 立即强制退出**；
- 移交失败不再抛错，统一降级为「移交未能完成（原因），房间已关闭。」（服务端本来就会在房主断线时关掉房间，所以不会留下僵尸房间）；
- `before-quit` 增加 **5 秒硬看门狗**，本地服务关闭或会话清理卡住也一定退出。

## 保持不变

- 房间逻辑、鉴权协议（`peerAuthProtocol: 2`）、媒体链路顺序（原生 P2P → VDO 直连备用 → TURN 仅中继重试）与所有安全边界不变。
- 自动更新流程与 SHA256 校验要求不变。

## 已知限制

- Windows 产物未签名，SmartScreen 可能提示；`SHA256` 只能证明文件与发布页一致。
- 覆盖安装没有回滚；装在无写权限目录（如 `Program Files`）时更新会失败并提示。
- 手机端连接**需要你在手机上实测确认**：本版修复的是"凭据过期"与"没有提示"，如果你的房间从未启用中继，仍需先在「设置 → 网络」里开启并测试通过。
