# Roomcast 0.14.3-beta.6

## 修复

**程序关不掉（TURN 建不起来、网页端连不上、房主移交失败时退不出）。**
关窗与退出原先被绑在网络结果上：移交失败时渲染层回 `ok:false`，主进程把它当**否决票**；那个 20 秒计时器到点只清掉自己的标志、并不关窗；`before-quit` 里的收尾没有任何期限。现在：

- 关闭窗口给 **2.5 秒**预算，到点**无条件关闭**；
- 2.5 秒内**再点一次 ✕ 立即强制退出**；
- 移交失败不再抛错，统一降级为「移交未能完成（原因），房间已关闭。」（服务端本来就会在房主断线时关掉房间，所以不会留下僵尸房间）；
- `before-quit` 增加 **5 秒硬看门狗**，本地服务关闭或会话清理卡住也一定退出。

## 保持不变

- **连接路径与 `0.14.3-beta.5` 逐字节相同**：邀请链接的生成、信令、`peerAuthProtocol`、ICE 服务器接线、媒体链路顺序（原生 P2P → VDO 直连备用 → TURN 仅中继重试）一律未改动
  （`git diff v0.14.3-beta.5 -- src/App.jsx` 为空；`src/p2p.js` 的差异全部集中在房主退出用的 `leave()`）。
- 中继（TURN）的取用方式、房间与邀请里携带的中继信息、界面上与之相关的提示**均未改动**。
- 房间逻辑、鉴权协议与所有安全边界不变；自动更新流程与 SHA256 校验要求不变。

## 已知限制

- Windows 产物未签名，SmartScreen 可能提示；`SHA256` 只能证明文件与发布页一致。
- 覆盖安装没有回滚；装在无写权限目录（如 `Program Files`）时更新会失败并提示。
- 手机端连接问题的排查记录见 `docs/MOBILE-CONNECT-手机端连接失败分析与修复.md`：本版**没有**改动任何与"手机加入/ICE/中继接线"相关的代码；要判定责任需要真机 A/B（同一部手机、同一网络，分别跑 beta.5 与 beta.6）。
