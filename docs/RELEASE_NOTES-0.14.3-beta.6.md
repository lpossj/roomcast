# Roomcast 0.14.3-beta.6

更新于 2026-09-26T22:06:13+08:00。仅本地测试包，未发布。

## 本轮修复

- Windows第一次点击右上角X或Alt+F4直接结束程序，不等待房主移交、邀请链接、渲染器回复或本地服务收尾。补充原生关闭消息处理，覆盖渲染器冻结、beforeunload否决。
- 创建/加入期间可以点“停止连接”、弹窗关闭或Escape取消，立即恢复空闲；取消后的旧成功/失败结果不能恢复房间或覆盖新房间。
- 离房移交期间提供“停止等待并离开”，直接断开当前房间；移交或清理抛错仍清空本地状态，允许继续操作。
- 设置中的测试等待可以关闭，关闭后不应用旧结果；网页邀请关闭后忽略迟到结果。
- 自动更新仅销毁主窗口，更新窗口和下载继续；安排采集收尾不阻塞更新。
- 源码打包先检查工作区、完成临时ZIP后替换，失败保留旧源码包。

## 范围与验证

- TURN获取方式、地址、凭据、TTL、邀请内容、ICE政策及媒体车道顺序不变，不添加中继不可用提示；本轮调整的是取消边界与退出，不修链接或移交成功率。
- 相比beta.5，App与连接代码现在有用户授权的取消检查，旧“App逐字节一致/差异仅leave”说法仅适用于本轮之前的历史快照，不能用于当前包。
- 全套205/205、许可证、前端构建、网络门禁通过。非测试模式真实桌面中卡住连接可取消、取消后可以打开设置；冻结渲染器和beforeunload否决下标题栏关闭84ms退出，code0，自身8个进程无残留。
- 实际打包后的结果、源码来源和校验值以本地release/BETA6-LOCAL-VALIDATION.md为准；时间戳全记录见docs/EXIT-CANCEL-20260926.md。

## 验证边界

- 同号beta.6本地重打包，未push/tag/Release，手机站点未部署。
- 手机跨网连接根因仍未确定；本轮没有声称修复手机连接、TURN或移交协议。用户进行真实使用测试。
- 用户点击X会结束房间与共享，不等待房主移交。要保留房间，请先正常离房并完成移交。
