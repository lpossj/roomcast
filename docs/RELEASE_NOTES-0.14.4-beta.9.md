# Roomcast 0.14.4-beta.9

- 桌面邀请默认具备按需 EasyTier 备用能力，移除创建房间时的手动开关。普通 IPv6/IPv4 优先；未连通且未开始鉴权的桌面入房等待 8 秒后尝试备用。
- 屏幕观看继续按用户独立回退，双方按需参与组网；正常连接保留原路线。
- 房间标签按实际 ICE 路线更新。具备备用能力或某路视频使用 EasyTier，不再代表整个房间都使用 EasyTier。
- 并行准备本机连接和原有中继配置，提前预连接信令，新建房间跳过空聊天历史，并增加本地创建阶段耗时记录。
- 成品统一为 `Roomcast-0.14.4-beta.9.exe` / `.zip`，更新识别兼容历史 Windows 命名。

没有校园网真机耗时/吞吐结论；公共信令、双方权限和转发带宽仍会影响实际体验。Windows 成品为本地交付，尚未上传 GitHub；电脑和手机共用的网页已于 2026-10-11 经明确授权部署至 https://roomcast-2dy.pages.dev/。
