# Roomcast 0.14.4-beta.7 Beta

Windows 10/11 x64。客户端与[网页版](https://roomcast-2dy.pages.dev/)同步更新。

## 变更

- 重做自动更新：下载和暂存校验、独立更新进程、原子替换、新版实际界面启动确认；失败回滚并保留诊断日志。
- 自定义头像：在设置中选择 JPG/PNG/WebP，裁剪压缩后保存图片副本，删除原图片不影响头像。同步人物栏、共享预览、小窗和全屏。共享头像保持原有显示样式，鼠标移动显示、静止两秒隐藏。
- 独立房间语音：人物栏底部麦克风调节自身发送音量，成员声音开关/滑条仅控制其他成员的麦克风。共享画面音量和所有软件提示音保持独立。麦克风和成员声音默认关闭，两个音量默认 50%。
- 麦克风测试包含本地实时耳返和电平显示，不录音。设置可选择下次入房默认开启麦克风/成员声音。人物栏头像说话时显示绿圈，共享小头像不增加绿圈。
- 每位其他成员旁的音量按钮独立调节你听到的该成员麦克风，不受角色限制；默认 100% 保持原响度，离房重置。
- 管理闭麦：房主可关闭管理员和普通成员麦克风，管理员只能关闭普通成员。服务端拒绝越权和闭麦前的在途开麦请求；之后可主动重新开启。

## 验证与边界

发布回归、两端浏览器实际 WebRTC（假设备）、桌面偏好重启及耳返、共享和成员音量隔离、提示音独立、分级闭麦与旧 beta.6 房主兼容均做本地验证。具体完成记录见仓库状态说明。

真实麦克风声学质量、公网多 NAT、移动设备原生全屏尚未完整真机验收；iPhone 原生视频全屏的覆盖层受浏览器能力限制。当前 CDP 环境未成功验证原生小窗标题区拖动，未更改该实现。

头像同步、房间语音和管理闭麦需由 beta.7 房主创建房间；新版网页加入旧版本房间保留共享与聊天。旧版本自动更新失败时请手动下载本版；本版包含重做后的后续更新流程。

Windows 程序未签名。下载后可用 SHA256.txt 核对 Windows EXE/ZIP 和附带 OBS 源码；安全问题报告见 [SECURITY.md](https://github.com/lpossj/roomcast/blob/main/SECURITY.md)。
