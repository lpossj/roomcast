# Roomcast 校园互联

本次实现参考成熟桌面组网客户端的“应用管理独立 EasyTier 核心与虚拟网卡”方式，没有复制 MCTier 的应用代码。只接入校园互联相关模块，现有 TURN 取得方式保持不变。

## 使用流程

从 0.14.4-beta.9 起，Windows x64 桌面端默认具有按需 EasyTier 备用能力，不再手动选择开关。桌面邀请附带独立校园组网密钥，其他桌面成员转发邀请时保留该密钥。创建和普通连接成功时不启动网卡；真正尝试备用路线时，双方才参与组网并允许 Windows 权限请求。无需注册 EasyTier 账号或另外安装核心。

创建房间只生成备用组网密钥，不启动网卡或要求提权。桌面邀请先走原有 IPv6/IPv4；普通入房明确失败，或 8 秒时 ICE/数据通道仍未连通且未开始鉴权，才单独尝试 EasyTier。已连通普通 ICE 的连接保持原有鉴权窗口；认证失败不触发备用路线，公共信令不可达也不靠组网修复。旧邀请没有备用密钥时保持普通流程。

屏幕观看保持点击进入：P2P/VDO 普通直连均未建立可播放画面后，仅该观看者尝试 EasyTier；后续普通画面连接进入失败状态也可尝试。双方桌面需具备相同校园密钥；共享者作为对端按需启动，其他正常观看者不重建连接。EasyTier 失败后沿用原有公网 TURN 获取与回退逻辑。

回环 ICE 适配层仅监听本机随机 UDP 端口，通过本机随机凭据向 Chromium 提供真实虚拟网候选。它使用 TURN 协议作为本机适配协议，不是新增公网 TURN 服务，不修改用户的公网 TURN 配置。虚拟网流量仍受原有同子网 UDP 50000–50255 ACL 约束；不再修改主窗口或浮窗的 WebRTC 端口范围，不再伪造 mDNS 候选。

网页邀请删除 campus 参数，保留普通入房认证、信令与原有中继参数；浏览器没有 EasyTier 备用能力。EasyTier 需要双方配合，无法让一台单独装有组网的观看端接通未参与组网的对端。

会话按备用连接引用保留，最后一个备用连接关闭或退出房间时回收；共享启停不会关闭仍承载房间或其他画面的组网。提权取消、组件失败或网卡失效只影响备用连接，不主动断开仍正常的普通连接。取消正在等待的画面会按请求标识通知共享者回收。

显示 EasyTier虚拟网 依据已选中的 ICE 候选对与房间虚拟子网，而非房间开关；本机预览可显示多位观看者的实际路线。EasyTier 底层究竟打洞直连还是公共节点转发仍标记未知，不把虚拟网连通等同于底层 P2P 成功。

右上角表示当前成员的房间控制连接：房主显示 P2P，加入者根据实际候选对每 3 秒更新 P2P直连、TURN中继或 EasyTier虚拟网。某个观看者的视频使用 EasyTier，不会把房主或其他成员的房间连接标签一并改成 EasyTier。当前本地产物为 `release/0.14.4-beta.9/Roomcast-0.14.4-beta.9.exe` 和同名 ZIP；研究依据及未确定范围见 `docs/EasyTier国内视频与创建等待审查-2026-10-11.md`。

## 安全边界

- 每个房间使用随机密钥与域分离 HKDF 派生组网密钥，显式启用 AES-256-GCM；校园密钥与 Roomcast 入房认证密钥分开。
- 主进程只接受主窗口发来的严格格式参数；每次会话有唯一 lease，旧会话清理不能关闭新会话。地址及命令不由邀请自由指定。
- 虚拟网卡 ACL 默认拒绝，只允许当前房间子网中的 UDP 50000–50255；禁止代理转发、出口节点、自动接受其他成员的子网路由、UPnP 和 DNS 接管。仅本机适配器在虚拟网卡分配这个端口段，普通 WebRTC 端口策略不变。
- 配置写入前设置 Windows 目录 ACL，仅当前用户、SYSTEM 和管理员可访问。密钥不放入命令行；退出、取消授权和启动失败后删除配置文件。
- 校园核心作为单独进程提权，Roomcast 主程序保持原权限。监督进程检查父进程身份、拒绝重解析路径、锁定并核对核心/驱动/配置摘要，清除 ET_* 环境覆盖。
- 核心纳入 Windows Job，监督进程消失时关闭核心；正常退出、父进程退出、取消加入时回收自建防火墙规则。主进程/网卡异常会结束校园会话。
- 定制核心不启动管理 RPC，不加载 Npcap 抓包 DLL，也不创建上游默认的宽泛网卡防火墙规则；由监督模块管理本次会话的规则。摘要基准放在 app.asar，独立于外置运行组件；这属于组件完整性保护，不能保证抵御已控制当前 Windows 账户或管理员的攻击者。

仍存在的边界：共享校园密钥的成员属于同一组网信任域，现有 Roomcast 入房认证继续独立生效。踢人/刷新入房密钥不会同步轮换整个虚拟网络，需新建房间才能更换校园密钥。若监督进程被强杀或系统断电，系统中的防火墙规则可能来不及删除；其作用仍限定为指定程序及对应网卡。DHCP 后续发现地址冲突而换址时，仅备用会话结束，普通连接继续保留；受影响观看者可重新连接。

## 构建与分发

固定 EasyTier 2.6.4，源码 commit `8428a89d2dabc94c97d370ec607c6ca142473626`，核心版本标识为 `2.6.4+roomcast.1`。`npm run prepare:campus` 准备组件；Windows 打包的 beforePack 也自动调用。此次使用 Rust 1.95.0、MSVC Build Tools，固定 protoc 26.0-rc1、YY-Thunks 1.1.7 和 VC-LTL 5.2.2。首次准备需要网络，成功后按构建配方和摘要复用本地组件。

本机 Rust 工具链只安装在 `runtime/build-tools`，没有修改系统 PATH。Windows 非 ASCII 工作目录通过临时 ASCII junction 映射构建，目标必须指向当前工作目录，以避开 protoc 对中文 include 路径的处理问题。运行时文件仍使用实际路径，拒绝重解析路径。

本机准备流程使用 Cargo registry 的较短路径编译，离线 vendor 配置仅写入交付源码包；缓存目录保存该配置备份。若解压交付源码自行重建，应选择较短的 ASCII 路径（例如 `C:\rc-et`），避免 MSVC 打开 vendor 头文件时超过 260 字符边界。

准备脚本从固定 SHA256 的上游源码和 pnet crate 编译核心。独立补丁禁用 Packet 接口、改用 IP Helper 返回网卡、删除管理 RPC、约束 DHCP 使用配置网段并允许首位成员建立网卡。官方预编译核心不作为备用路径。

Wintun 0.14.1 使用官网签名 DLL 与配套再分发许可证。交付资源包含 LGPL 许可证、修改后的 EasyTier/pnet 源码、Cargo.lock、vendor 依赖源码与重建说明，以及 YY-Thunks、VC-LTL 的对应源码和原许可证。上游源目录本身也包含 Packet.dll/Packet.lib，源码压缩包明确排除这两个不使用的文件。

历史内置实现阶段已生成定制核心、Wintun、辅助脚本、对应源码、许可证和信任清单，前端构建与最终组件准备均成功。本地 Windows ZIP 已生成于 `release/beta8-campus-20261011/Roomcast-0.14.4-beta.8-Windows.zip`，也保留同目录的 `win-unpacked`。解压后运行 `Roomcast.exe`，使用校园模式时双方需允许 Windows 权限请求；成品不要求用户安装 Rust、EasyTier 或 OBS。

按要求未运行自动化测试、软件启动验证或校园网真机连接验证。打包流程保留生成成品所需的组件完整性检查；编译/打包成功不代表已经验证陌生电脑上的驱动安装、权限流程、媒体连接或校园网打洞成功率。此 ZIP 为本地产物，未上传发布。详细过程、实际时间和失败记录见 `docs/时间戳记录/2026-10-11-EasyTier内置实现.md`。

## 2026-10-11 按需回退方案来源与边界

参考 EasyTier 官方列出的 [GUI/EasyTierGame 集成](https://easytier.rs/guide/installation_gui)，保留既有独立内核和 Wintun，不更换大包。官方 [SOCKS5](https://easytier.rs/en/guide/network/socks5) 需要应用代理适配，不能直接替代浏览器 WebRTC 的 UDP 候选。Electron [窗口端口范围 API](https://github.com/electron/electron/blob/main/docs/api/web-contents.md) 作用于整个窗口，因此取消该全局限制。

本机适配库固定 [turn-server 0.6.6](https://github.com/colocohen/turn-server)，Apache-2.0；只使用 UDP 服务端，禁用其他传输与 TCP 代理，只允许本房间虚拟子网和限定端口，并设连接/分配配额。它处于 1.0 前开发阶段，不能宣称与 EasyTier 核心同等成熟，未实测 Chromium 互操作及吞吐。源码审查排除了旧 node-turn 0.0.6，其租约回收和续租实现不适合直接使用；该依赖已经撤销。

普通入房保留原 25 秒 ICE 和 8 秒鉴权等待；实际失败事件可能更早触发备用。备用过程为双方 Windows 授权分别保留启动时间，允许取消。仍依赖 PeerJS 可达性、双方升级和授权、公共 EasyTier 节点可达性。没有新增、恢复或运行功能/烟雾测试。当前任务产物以 docs/时间戳记录/2026-10-11-EasyTier按需回退.md 末尾记录为准，上述旧 ZIP 不代表包含当前修改。
