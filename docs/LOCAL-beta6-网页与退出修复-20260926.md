# beta.6 本地修订验收

本文件针对用户真机反馈后的新修订；此前已公开的 beta.6 Release 及原验收记录保留原始含义。版本仍为 0.14.3-beta.6，本次未授权替换远端标签、附件或部署网页。

## 改动

- 同文档收到邀请也显示加入确认；新网址优先于旧缓存，粘贴完整网页链接可解析邀请。仅显示确认，不自动入房。
- 房主独立清理无响应成员，不依赖微信网页是否发出关闭事件；正常/忙碌回复保留。旧网页已支持所复用的只读探测。
- 现有离开入口第一次直接清理，不等待移交；去掉额外停止按钮，既有弹窗 ×/Escape 仍可取消卡住请求。Windows X/Alt+F4 直接进程退出入口保留。
- 单项停止异常不会跳过其余连接或轨道释放。不改 TURN、ICE、鉴权和媒体车道。

独立回滚提交：邀请 fe2d19a；现有离开入口 0281295；失联成员清理 4095bdc；资源释放 e8581a6。

## 本轮验证

- 完整 check 通过：许可证、测试、Vite 构建、网络门禁；新增最后两项回归后最终全套 216 项，215 通过、0 失败、1 项可选旧 beta.1 ZIP 测试因未提供旧包而跳过。
- 真实 Socket.IO 房间回归：无 close 的失联成员被服务端删除并广播；同名、仍回应的另一成员保留。
- 390×844 手机视口、无窗口 Edge：连续 hash 邀请、popstate、query 覆盖旧邀请及完整网址预填通过；每次需要用户确认，页面异常 0。已检查截图布局。
- 非 TEST_MODE 的开发 Electron：卡住请求点原有 × 可取消并打开设置，后续连接可 Escape；冻结渲染器且 beforeunload 否决后 WM_CLOSE 72ms/code0，自己的 8 个进程无残留。
- 新本地 EXE/ZIP 与打包版本实际关闭验证尚待构建完成后追加，不能用此前公开附件的验收代替。

## 使用和边界

- 成员失联清理在正常调度下约 25 秒内；休眠/冻结和极端网络延迟不能保证精确时刻。
- 用户主动离开直接结束当前连接。需要保留房间时，先通过成员管理主动移交，不把移交等待放到退出路径。
- 当前线上静态网页已核对为旧 beta.3。桌面新包能对旧网页做存活清理；新的邀请 UI 需要部署新网页后手机线上才会得到。
- 本轮未做 iOS/微信真机验收，不声称跨网连接、移交成功率或所有未知异常已经修好。原生关闭与 JavaScript 取消/清理分属不同边界。
