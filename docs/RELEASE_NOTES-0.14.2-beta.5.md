# Roomcast 0.14.2-beta.5

## 本版变更

- 电脑和手机网页可以创建 P2P 房间；浏览器内运行与桌面端相同的房间规则，不依赖桌面本地 API。
- 修复手机网页默认显示聊天室、成员栏无法打开或关闭的问题。
- 手机网页退出时主动断开房间连接，便于桌面端及时更新成员；浏览器恢复前台时重新声明观看状态并尝试恢复画面。
- 网页端设置不再请求桌面配置接口；本地服务状态只在桌面端显示。网页图片复制和下载使用浏览器能力。
- 保留小窗置顶开关与原有 P2P 优先的媒体路径。

## 使用和限制

桌面应用创建的网页入口由应用自动提供，无须另开服务。收到该 HTTPS 链接的电脑或手机浏览器可以建房、入房；网页建房者需保持页面运行。Cloudflare Quick Tunnel 免费但属于测试用途，地址可能变化，服务稳定性没有保证。部分手机浏览器在后台会暂停 WebRTC 和视频播放，返回前台后会尝试恢复；不同内核仍需实机确认。

网页入口只提供静态文件，不开放桌面本地 API、Socket.IO 和管理接口。房间邀请链接含入房凭据，应只发给预期成员。
