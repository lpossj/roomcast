# Roomcast 0.14.3-beta.7

Beta 预发布：修复网页邀请确认、失联成员清理和首次离开行为，并更新线上观看网页。

## 变化

- 在已经打开的网页中粘贴新邀请网址，也会重新显示加入确认；新邀请优先于旧缓存，支持粘贴完整网页邀请。只有点击“进入房间”才加入。
- 房主独立检查已加入成员的响应，网页关闭/冻结却没有及时发出断开事件时，清理该成员连接；正常或忙碌回复仍保留。正常调度下约 25 秒内处理无响应成员，不依赖微信关页事件。
- 点击原有“离开房间”入口首次就清理当前连接，不等待移交，也不要求另点停止按钮。卡住创建/加入时，既有弹窗 × 或 Escape 可取消并继续其他操作。
- 一项采集或连接释放失败不再阻止其余资源释放。Windows 右上角 × 和 Alt+F4 保留直接进程退出边界，覆盖渲染器冻结及网页阻止关闭。
- 更新 `https://lpossj.github.io/roomcast/` 的观看网页。只有客户端创建房间；手机网页观看，电脑网页加入后可共享但不能建房。此版本不提供 WebViewer ZIP 附件。

## 下载与验证

Windows.exe 为便携程序，Windows.zip 解压后运行 Roomcast.exe，选择一种即可。source.zip 包含源码、审查方案和时间戳；loopback 与 OBS 源码为必要组件及第三方源码，SHA256.txt 用于校验。

本版本完整检查通过：215 项通过、0 失败、1 项可选旧版 ZIP 测试跳过；实际便携包及未启用 TEST_MODE 的打包程序通过校验。冻结渲染器并阻止网页关闭后，原生关闭 70ms/code0，自己的 7 个进程无残留。手机和电脑浏览器入口/邀请确认回归通过，微信真机仍待验收。

实际发布与网页核对结果记录在 [beta.7 验收单](https://github.com/lpossj/roomcast/blob/main/docs/RELEASE_CHECKLIST-0.14.3-beta.7.md) 与 [时间戳](https://github.com/lpossj/roomcast/blob/main/docs/时间戳记录/发布-beta7-20260927.md)，不会把此前 beta.6 包的验证当成本版本验证。

## 边界

- TURN 获取、ICE、鉴权及媒体车道不变，不添加中继不可用提示；本版不宣称修复所有跨网连接或移交成功率问题。
- 主动离开会立即结束当前连接；要保留房间，请先在成员管理中完成主动移交。手机/微信的生命周期及极端网络延迟仍需真机验收。
- Windows 产物未签名，版本仍为公开测试版。旧版 beta.6 及其附件保留，可从发布历史回退。
- 问题反馈：[GitHub Issues](https://github.com/lpossj/roomcast/issues)；数据及许可边界见仓库 PRIVACY.md、SECURITY.md 和第三方声明。
