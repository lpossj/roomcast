# Roomcast 状态与验证边界

当前发布线：0.14.x 公开测试版（Beta）。
当前平台：Windows 10/11 x64。

## 已验收

本轮已在干净 Windows 环境完成基础验收：

- 无系统安装 OBS 时可启动。
- OBS Virtual Camera 首次注册 UAC 正常。
- OBS 固定 FPS 采集正常。
- Electron / Chromium 原生采集正常。
- 系统声音捕获正常。
- 麦克风、聊天、图片功能正常。
- P2P 优先、VDO 3 秒延迟、TURN relay-only 兜底路径符合设计。
- 本机服务监听 127.0.0.1。
- 退出后无 OBS / Electron / Roomcast 残留。

详细检查表见 docs/RELEASE_CHECKLIST-0.14.2-beta.1.md。

## 尚未充分验证

下列项目不代表当前版本不可用，只表示还没有足够广泛的证据：

- 不同公网 NAT、IPv6、VPN、Tailscale 和全 UDP 封锁组合。
- 长时间运行、弱网抖动、丢包恢复和 CPU/GPU 高负载。
- 多房间同时使用 SFU / TURN 的容量和恢复。
- 移动端浏览器观看；当前没有浏览器免安装观看入口。
- 旧版本与新版本混合使用时的完整兼容矩阵。
- 代码签名包在 SmartScreen 和不同 Windows 版本上的表现。
- 真实游戏音频与视频长期同步。

## 发布定位

当前适合作为公开测试版发布，不建议宣称为稳定版或正式版。发布时应明确：

- 未签名状态；
- Windows x64 平台限制；
- 观看者和房主都需要安装 Roomcast；
- 默认可能使用 PeerJS / VDO.Ninja 公网服务；
- TURN 需要自行配置；
- 房间和聊天数据是内存态。

## 更新规则

每次发布后应更新本文：

- 新增已验收项；
- 移除已修复的未验证项；
- 保留仍未验证的物理环境项；
- 如果某次验收被后续证据推翻，必须记录原因。
