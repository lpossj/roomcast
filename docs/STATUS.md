# Roomcast 状态与验证边界

当前Windows桌面版本：0.14.4-beta.3，Windows 10/11 x64。线上网页仍为0.14.4-beta.2，网页入口为https://roomcast-2dy.pages.dev/，本次未部署网页。本轮修复与验证见[beta.3说明](RELEASE_NOTES-0.14.4-beta.3.md)。

## 当前功能

- Windows桌面和HTTPS网页均可创建房间、生成邀请、观看和聊天。
- 桌面保留OBS固定FPS/Virtual Camera与原生采集，系统、应用、排除应用声音及麦克风沿用。
- 网页按安全上下文、浏览器API和权限提供摄像头/屏幕采集；没有所选程序声音/排除程序声音入口。手机是否能采集由实际能力决定，不按设备类型承诺屏幕共享。
- 网页房主应保持前台；后台挂起或关闭页面可能中断协调服务。
- 媒体路径保持原生P2P优先、VDO direct备选、直连耗尽后TURN兜底；本机服务默认127.0.0.1，不改TURN取用方式。

## beta.3 本轮实际验证

- 清理后日常回归249项、完整发布回归260项全部通过，0失败、0跳过，分别约2秒和21秒；许可、构建、网络门禁通过。
- 最终EXE/ZIP已本地生成；OBS包内启动/参数/枚举、便携预检、欢迎页/版本/资源、便携二次启动、ShareModal后端切换通过。
- 28个生产文件与asar一致，ZIP六个关键文件一致，版本摘要已生成；旧beta.2成品及摘要保留。
- 隔离成品使用TEST_MODE或专用预检，不能推定用户火绒、正常首次UAC与公网实播均已验证。

## beta.2 历史实际验证（不代表 beta.3 结果）

- 本地249项中248通过、0失败、1历史包条件跳过；云端CI249项中246通过、0失败、3条件跳过。
- 最终EXE隔离启动、版本与资源检查通过；28个生产文件与asar相等，ZIP关键文件摘要一致。
- OBS真实1080p60桥接、本机Chromium双pc静止30秒/动态14秒A/B通过；没有复现用户严重动态模糊，不能声称已彻底解决。
- 线上网页资源的建房、邀请、聊天、假摄像头1080p传输、停止释放、权限门控和无两项原生声音按钮检查通过。信令隔离模型不等于真实公网媒体验证。
- 两处云端检查夹具缺陷已修复并定向实测通过。完整Release workflow曾失败，最终交付采用本地验收包直接上传，未把失败写成成功。
- 用户此前确认手机连接正常；这不等于新增手机摄像头/屏幕采集和所有移动环境已实测。

## 尚未完成的验收与风险

- 原Electron进程号码错误无原文，未确定根因。
- 新DLL加固后的干净机器首次UAC注册、手机新增采集硬件、公网IPv6/IPv4/TURN UDP/TCP/TLS完整矩阵未实测。
- 真实弱网模糊/恢复时长、连续高动态、静止1分钟CPU/GPU/网络完整对照、长期多成员资源占用仍缺数据。
- 程序未签名，SHA256不能代替发布者身份认证；认证未绑定DTLS通道，主动代理风险仍在；Worker平台限流尚未部署。
- 新Viewer要求Host proof；旧Host和新Viewer不保证兼容。升级边界见[版本策略](VERSIONING.md)和[发布说明](RELEASE_NOTES-0.14.4-beta.3.md)。

## 交付与升级

Release仅提供Windows EXE、目录版ZIP、SHA256及对应OBS源码；Roomcast源码使用GitHub自动生成的Source code入口。beta.2可由既有更新检查发现beta.3；也可从发布页手动下载。完整VDO权限回收需要所有共享者升级，旧观看者可能需要重新进入观看。

房间/聊天为内存态，不引入本地数据库，隐私约定不变。历史干净Windows/UAC等结果不能代替本次验证。
