# Roomcast 状态与验证边界

当前本地开发版本：0.14.4-beta.8，按用户授权准备打包、同步网页及发布；当前公开版本仍为 beta.7。变更见 [beta.8说明](RELEASE_NOTES-0.14.4-beta.8.md)。beta.7 附件与网页部署 d46198fe 保留为历史基线。

## 当前功能

- Windows桌面和HTTPS网页均可创建房间、生成邀请、观看和聊天。
- 桌面保留OBS固定FPS/Virtual Camera与原生采集，系统、应用、排除应用声音及麦克风沿用。
- 网页按安全上下文、浏览器API和权限提供摄像头/屏幕采集；没有所选程序声音/排除程序声音入口。手机是否能采集由实际能力决定，不按设备类型承诺屏幕共享。
- beta.8 网页切后台不主动离房，开放连接上的成员不因 JS 暂停而被定时移除；标签标题显示后台共享/聊天。操作系统终止页面、断开网络或冻结房主仍可能中断协调服务，不保证浏览器后台持续运行。
- 媒体路径保持原生P2P优先、VDO direct备选、直连耗尽后TURN兜底；本机服务默认127.0.0.1，不改TURN取用方式。

## 尚未完成的验收与风险

- 原Electron进程号码错误无原文，未确定根因。
- 新DLL加固后的干净机器首次UAC注册、手机新增采集硬件、公网IPv6/IPv4/TURN UDP/TCP/TLS完整矩阵未实测。
- 真实弱网模糊/恢复时长、连续高动态、静止1分钟CPU/GPU/网络完整对照、长期多成员资源占用仍缺数据。
- 程序未签名，SHA256不能代替发布者身份认证；认证未绑定DTLS通道，主动代理风险仍在；Worker平台限流尚未部署。
- 新Viewer要求Host proof；旧Host和新Viewer不保证兼容。升级边界见[版本策略](VERSIONING.md)和[发布说明](RELEASE_NOTES-0.14.4-beta.3.md)。

## 交付与升级

Release仅提供Windows EXE、目录版ZIP、SHA256及对应OBS源码；Roomcast源码使用GitHub自动生成的Source code入口。可由既有更新检查发现新版本，也可从发布页手动下载。完整VDO权限回收需要所有共享者升级，旧观看者可能需要重新进入观看。

房间/聊天为内存态，不引入本地数据库，隐私约定不变。历史干净Windows/UAC等结果不能代替本次验证。
