# Roomcast 0.14.4-beta.3 Beta

Windows 10/11 x64 修复版。线上网页仍为 beta.2，本次未部署网页。

## 修复

- 启动读取 OBS 虚拟摄像头注册状态改为限时、只读的 `reg.exe` 查询，保留中文路径；查询失败不会被误判为缺失并触发自动管理员注册。
- 踢出成员后，轮换 VDO 发布凭据并停止旧发布媒体，授权 VDO 观看者自动重连；成功的原生 P2P 和 TURN 观看继续播放。
- 共享权限被撤销时，停止本机采集、声音和媒体发布。
- 异常图片传输会通知接收端中止，并限制接收缓冲数量和存活时间；切换房间后，旧图片处理和迟到的聊天历史不会写入新房间。
- 已鉴权但25秒内未入房的连接会释放占用，避免访客槽长期被占满。
- 修复画面稳定观察跨过总期限后再失败时，媒体竞争可能悬挂的问题。
- 更新安装前拒绝会被命令解释器展开的危险路径，并校验版本文本。

媒体仍使用原生 P2P 优先、VDO direct 备选、直连耗尽后 TURN 兜底；TURN 取得方式、采集后端和音频选项保持原有行为。

## 测试与成品验证

- 删除10项重复或过时检查。日常 `npm test` 的249项全部通过，约2秒；发布 `npm run test:release` 的260项全部通过，约21秒，无失败或跳过。11项多人迁移、超时和恢复场景保留在发布检查中。
- 许可、生产构建和网络门禁通过。
- Windows EXE/ZIP 打包完成；包内 OBS 启动、1280×720/60FPS配置、来源枚举、虚拟摄像头 DLL 和便携资源检查通过。
- 便携启动、版本和资源、第二次启动及共享设置后端切换检查通过。28个生产文件与 `app.asar` 一致，ZIP六个关键文件与解包目录摘要一致。

## 验证边界

启动的只读注册查询已移除PowerShell；首次管理员注册、按需音频枚举及更新启动器仍可能使用PowerShell。未在用户实际火绒规则下复测，不能保证所有告警均已消除。

干净机器首次注册/UAC、真实公网多成员媒体及完整手机/硬件矩阵尚未验证。应用未签名，SHA256只能校验文件一致性。既有DTLS通道绑定风险仍在，其他限制见[状态文档](STATUS.md)。安全问题请通过[安全报告渠道](../SECURITY.md)反馈。
