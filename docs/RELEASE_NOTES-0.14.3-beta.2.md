# Roomcast 0.14.3-beta.2

## 修复

默认网页入口改为固定 HTTPS 静态观看站点。分享弹窗本地生成完整邀请，不再启动 cloudflared、申请临时地址或等待隧道连接。分享者和观看者无需注册、登录或设置网站账号。邀请格式、房间控制、采集与 P2P/VDO/TURN 媒体流程保持原有协议。

网页构建支持根路径及子目录，网页成员再次分享时保留部署目录。新增固定入口无本地构建、无隧道组件条件下的测试，以及非法站点地址拒绝测试。

## 边界

固定站点只负责提供页面。各地区到 GitHub Pages、公共信令及媒体服务的可达性仍由实际网络决定，不保证所有网络都能连接。房间结束后站点仍可加载，但完整邀请只在原房间生命周期内有效。

本次最小修改保留旧 cloudflared 发布资源及 SHA256 校验，但生成邀请不会启动它。版本继续为公开测试版，Windows 产物未签名。最终测试和发布结果见同版本检查表。

## 本轮结果

166 项测试、构建及架构检查通过；网页已上线并逐文件校验；便携 EXE 启动与资源校验通过。新打包桌面端与实际 HTTPS 网页在同机完成入房、聊天及再次分享。验证不覆盖手机真机、跨运营商及长期媒体弱网矩阵。
