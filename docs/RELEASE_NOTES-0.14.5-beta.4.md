# Roomcast 0.14.5-beta.4

修复邀请参数传递、原生协商取消与回退，并统一真实编码能力和接收声明。没有新增依赖或设置项，码率上限、EasyTier方案及TURN取用保持原样。

- 系统链接打开邀请时保留校园密钥与自定义信令地址，与在程序内粘贴完整邀请一致。
- 已取消或被替代的观看请求不再建立迟到的浏览器连接。原生协商早期失败在同请求内完整回退，答复后的失败仍走已有恢复。
- 从实际编码首帧读取H.264 SPS级别，按真实码流协商，保留720p等低规格配置。接收端通过浏览器已有能力查询，仅在确实支持时声明相应1080p60/1080p30/720p60能力；查询缺失、失败或超时保留原offer。
- 需要音频但接收端未提供兼容Opus时完整回退，避免静默丢失音轨。普通浏览器发送、TURN、校园备用及VDO保持已有路径。
- 发布流程补齐项目源码ZIP及其校验值；自签名辅助脚本使用当前成品命名。本版仍沿用未签名分发。

本轮针对检查：邀请旧新函数及13项边界、9项原生协商时序、7项真实helper协商、11项接收能力分支、3项主进程启动/取消边界通过；普通浏览器双方协商保持stable。实际OBS 1080p60和720p60分别取得正确SPS，停止后不再输出帧。检查覆盖本轮变化，不作为全部校园网络或所有设备的性能保证。

电脑及手机网页使用同一生产站点，部署和页面检查结果见交付记录。旧浏览器缺少能力查询时继续使用兼容路径，不要求安装Windows组件。校园网的公共信令、节点可达性和NAT限制仍需具体网络条件支持。
