# Roomcast 0.14.2-beta.8

本版修掉 `0.14.2-beta.7` 之后在手机网页端暴露的三个真实缺陷，并删除网页端根本无法实现的界面入口。

## 修复：手机切后台会把电脑房主锁在房间里

- 现象：手机网页切到后台后仍显示在线，桌面房主点"离开房间"退不出去；手机切回来提示房间不存在，之后桌面才显示手机离开并能退出。
- 原因：房间交接要求房主把房间迁移给一个**能应答探测**的成员。被挂起的手机页面无法应答，于是没有任何合格接管者，`leave()` 直接抛错，房主被卡住。
- 修复：
  - 房主退出时如果**没有任何成员应答**（说明无法交接），不再抛错，而是关闭房间并明确提示"其他成员当前无法接管房间，房间已关闭"。仍有成员应答但交接失败时依旧保留原来的可重试提示，不会误关健康房间。
  - 网页端页面在后台停留超过 30 秒会主动退出房间（返回后可直接重新加入），从根上避免"僵尸在线成员"。

## 修复：手机网页发送图片后半个屏幕变黑

- 现象：手机网页发送一张照片后 UI 出现大片黑屏，只有重新进入页面才恢复。
- 原因：待发送缩略图与聊天缩略图都以**原图分辨率**解码。一张 4000×3000 的照片在 52×52 的小图里也要解码约 48 MB 位图，聊天区再解一次；手机上几份这样的位图会把合成器的瓦片挤掉，于是 UI 出现黑块。
- 修复：暂存前先按文件头读出尺寸，长边超过 2000 像素的照片缩放后以 WebP 重新编码（GIF 保持原样以免丢失动画，浏览器不支持 WebP 编码时保留原图），同时修正待发送缩略图的元素尺寸。

## 变更：删除网页端实现不了的入口

- 不提供屏幕采集的浏览器（绝大多数手机浏览器）现在**不再渲染共享按钮**，而不是显示一个禁用的"仅支持观看"占位。
- 设置里只保留该客户端真正能用的分类：不提供采集的浏览器看不到"音频与采集"，非桌面端看不到"本地服务"。
- 只有桌面应用提供的"窗口模式"小窗按钮此前已按同样规则移除。

## 新增：设置二级导航与"关于"

- 设置改为左侧分类 + 右侧面板：通用 / 音频与采集 / 网络 / 本地服务 / 关于（按客户端能力裁剪）。
- "关于"包含版本号、作者与反馈渠道、源码仓库，以及使用声明、数据与隐私边界、许可与第三方组件说明。

## 验证

- 全量单元测试 **154/154** 通过；干净检出（无 `dist/`）下同样通过。
- 真实浏览器实测三处修复：
  - 访客加入后冻结其 JavaScript（模拟被挂起的手机页面），房主 **1.03 秒**退出成功并提示"其他成员当前无法接管房间，房间已关闭"；修复前会抛"当前没有响应正常的接管成员"并卡住。
  - 页面标记为隐藏后 **30.2 秒**自动退出房间并提示可重新加入。
  - 4000×3000 的照片暂存后为 2000×1500，待发送缩略图元素为 52×52，页面无可滚动溢出。
  - 不提供 `getDisplayMedia` 的手机浏览器上，共享按钮与"音频与采集"分类均不存在；"关于"显示版本 `0.14.2-beta.8`。

## 已知限制

- 手机浏览器能否共享手机屏幕取决于浏览器是否实现 `getDisplayMedia`；当前常见手机浏览器通常不提供该接口。
- 网页入口基于 Cloudflare Quick Tunnel（测试用途、地址可能变化、有并发限制），分享者需要保持应用或页面运行。
- 手机浏览器在后台会暂停 WebRTC 与视频播放，返回前台后会尝试恢复；不同内核仍需实机确认。
- 房间和聊天数据为内存态；本版按设计不引入本地数据库。
- 其他未验证项见 `docs/STATUS.md` 与 `docs/RELEASE_CHECKLIST-0.14.2-beta.8.md`。
