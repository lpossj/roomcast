# Roomcast 0.14.2-beta.4

## 本版变更

- 延续 0.14.2-beta.3 的小窗置顶开关：默认不置顶，用户可在小窗控制栏切换。
- P2P 房间的电脑／手机网页观看链接由桌面应用自动创建。房主只运行 Roomcast，观看者打开链接即可，无需上传独立网页包或启动第二个服务。
- 网页入口仅提供打包后的静态页面，不公开桌面本地 API、Socket.IO、音频捕获或管理接口。网页与媒体仍使用原有 P2P 房间和 WebRTC 通道。
- 邀请密钥放在 URL 片段中；网页读取后从地址栏移除，保留在当前标签页会话存储中以支持刷新。网页入口设置了 CSP、禁止嵌入、禁止 Referrer、禁止 MIME 猜测，并只允许读取打包时的页面资源。
- 内置 cloudflared 2026.9.2 Windows amd64 官方程序，下载时校验其官方 SHA256。房间结束或退出应用后关闭临时入口。

## 使用

创建 P2P 房间后打开“分享房间”，等待网页链接出现，然后复制给电脑或手机浏览器中的观看者。分享者保持 Roomcast 运行；观看者无需安装客户端。

此免费临时 HTTPS 入口基于 Cloudflare Quick Tunnel。Cloudflare 将其定位为测试和开发用途，不保证可用性或固定地址，且有 200 个并发请求的限制。网络受限时 P2P 媒体仍可能需要 TURN；本版不能保证所有网络都能直连。分享链接本身相当于入房凭据，请只发送给预期观看者。

## 验证

- 网页静态入口仅允许预期资源；API、Socket.IO、路径穿越和写请求被拒绝。
- 前端构建、项目检查与发布包校验通过（以实际执行结果为准）。
