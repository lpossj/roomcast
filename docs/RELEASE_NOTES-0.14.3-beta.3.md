# Roomcast 0.14.3-beta.3

## 新增

桌面端**全自动更新**。启动后发现新版本时，会在初始页面弹出更新提示：显示当前版本与最新版本、
完整更新内容，并提供「不再弹出此框」（记住该版本，下次不再自动提示）、「立即更新」与关闭按钮。

点「立即更新」后的流程：

1. 先关闭正在运行的程序 —— 复用原有的退出握手，房间交接、共享与聊天会话正常收尾，不是强杀进程；
2. 独立窗口显示下载进度与阶段：下载（含百分比）→ SHA256 校验 → 解压 → 关闭程序 → 准备重启；
3. 程序退出后覆盖安装目录（目录版）或替换程序文件（便携版），然后**自动重新打开**。

设置 → 关于 → 软件更新里仍然保留手动路径：检查更新、手动下载 EXE/ZIP、打开发布页、打开文件位置。

## 更新过程的可靠性

- **必须校验**：下载官方发布包，并用发布页的 `SHA256.txt` 校验；校验不一致或发布页未提供校验值时
  **不会安装**，只保留手动下载。
- **接口限流不影响更新**：GitHub 未登录接口每小时每 IP 只有 60 次，被限流时自动改用固定站点版本清单
  继续检查（不消耗接口额度），更新内容改从对应 tag 的源码读取；界面会如实标注这一情况。
- **失败不改动程序**：安装目标不合法、程序未在限定时间内真正退出、替换脚本未能启动等情况，
  都会取消更新并保留原程序不动，同时给出可重试的提示。
- **替换失败可查**：覆盖阶段失败会写日志，并在下次启动时提示失败原因与日志位置。
- 覆盖使用"只增改、不删除"的方式（`robocopy /E`），不会删除你放进程序目录的其它文件。

## 边界

- Windows 产物仍未签名，SmartScreen 可能提示未知发布者；`SHA256` 只能证明文件与发布页一致，
  不代表发布者身份认证。
- 覆盖过程**没有回滚**：中途断电或强制关机可能留下半新半旧的目录，需要重新下载安装包。
- 程序安装在 `Program Files` 等无写权限位置时，覆盖会失败并提示；可改用便携版或管理员权限运行。
- 更新失败时临时下载包会自动清理；若因权限原因残留，程序下次启动会清理超过 10 分钟的临时目录。

## 未改动

P2P/VDO/TURN 媒体流程、OBS 与原生采集、房间与聊天协议均保持原有实现；固定 HTTPS 网页入口的加入、
观看与房间内浏览器共享也保持原有实现。

## 本版发布后（2026-09-26 16:42）站点的一处调整

固定网页站点已重新发布：网页端改为**只用于"用邀请链接加入并观看"**，电脑浏览器在房间里仍可共享屏幕，
手机浏览器仍以观看为主；**创建房间（当房主）只由桌面客户端发起**，网页端不再提供建房入口。
本版的安装包不包含该改动（随下一个版本进入安装包），但邀请链接打开的页面已经是该行为。
