# Roomcast 使用教程与注意事项

适用版本：0.14.2 Beta（npm 版本 0.14.2-beta.2）

## 下载后核对 SHA-256

下载程序 ZIP 后，建议在解压运行前核对哈希值，确认文件与发布者提供的版本一致。

1. 打开下载文件所在的文件夹，在文件资源管理器的地址栏输入 `powershell`，按回车。
2. 在打开的 PowerShell 窗口中粘贴以下命令并按回车：

   ```powershell
   Get-FileHash ".\Roomcast-0.14.2-beta.2-Windows.zip" -Algorithm SHA256
   ```

3. 找到输出中的 **Hash**，与 GitHub Releases 发布页或同一发布页附带的 `SHA256.txt` 中**同名文件**的 SHA-256 值逐字符比较。字母大小写不影响结果。

- **完全一致**：下载文件与该校验值对应的发布文件一致。
- **不一致**：可能下载损坏、版本不同或文件被修改。先不要运行，确认文件名和版本后重新下载；仍不一致时联系发布者。
- **提示找不到文件**：确认 PowerShell 已打开在下载目录，并把命令中的文件名改为实际下载的文件名。

如果下载的是便携 EXE，请改用：

```powershell
Get-FileHash ".\Roomcast-0.14.2-beta.2-Windows.exe" -Algorithm SHA256
```

优先对照 GitHub Releases 发布页中的哈希值。只核对和程序放在一起的 `SHA256.txt`，不能排除程序和校验文件同时被替换。哈希一致用于核对文件完整性，不代表程序已经通过安全认证。


## 快速开始
1. 运行 Roomcast.exe。
2. 创建房间，填写昵称和房名。
3. 复制完整邀请链接并发送给好友。
4. 好友先启动 Roomcast，再打开邀请链接。
5. 选择采集方式和参数。

## 采集方式
- 优先 OBS，固定 FPS，画质更稳。
- 首次 OBS Virtual Camera 可能弹 UAC。
- 兼容性优先时用原生采集，但画质可能较差。
- OBS 失败不会自动切换，需要手动改原生。

## 网络与 TURN
- P2P 优先，VDO 3 秒后启动，TURN 是最终兜底。
- 校园网、公司网、严格 NAT 建议配置 TURN。
- Cloudflare TURN Worker 部署见 docs/Cloudflare-TURN部署.md。
- 长期 access key 不要发到公开群。
- 默认可能使用 PeerJS 公共信令和 VDO.Ninja direct fallback，详见 PRIVACY.md 和 docs/自建信令.md。

## 音频与聊天
- 可共享系统声音、应用声音和麦克风。
- 图片只支持 JPEG/PNG/WebP/GIF。
- 单张最多 10MB，一次最多 4 张。
- 房间聊天是内存态，关闭房间不保留历史。

## 常见问题
- 邀请进不去：配置TURN（设置里）。
- P2P 没画面：等待三秒会触发VDO的连接形式。再不行就配置TURN
- OBS 失败：切原生采集。
- 原生画质差：改回 OBS，并降低 FPS 或分辨率。
- Windows 提示未知发布者：当前未签名，确认来源后仍要运行。
