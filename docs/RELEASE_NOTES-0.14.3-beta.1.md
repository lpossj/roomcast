# Roomcast 0.14.3-beta.1

## 修复

桌面房主退出时，浏览器成员的房间交接探测等待从 1 秒延长至 3 秒。移动网络下仍在线、但响应超过 1 秒的网页成员不再被立即当作无人接管而关闭房间。没有成员应答时，原有关闭房间的处理保持不变。

## 验证边界

- 新增使用真实 `server/rooms.mjs` 房间规则与浏览器内存协调器的迁移测试，覆盖正常网页接管与延迟 1.5 秒应答的网页接管。测试先用哨兵证明网页服务分支执行；延迟场景在旧代码失败、修改后通过。
- `npm run check` 通过（164/164 单元测试）；Windows 便携版与 ZIP 已构建，OBS 包、便携版生命周期、采集后端切换及 `verify:release` 检查通过。`verify:release` 覆盖打包版欢迎页与资源校验，不覆盖真实公网房间移交。
- 自动化模拟不等于手机真机或公网弱网验证；不同浏览器后台挂起时能否持续接管，仍需真实设备复核。
- 版本继续为公开测试版。请核对发布资产的 `SHA256.txt`；程序尚未签名。
